# Dr. Ahmed Ayoub — Academic Portfolio

Public academic and research portfolio for Dr. Ahmed Ayoub, Assistant Professor of Computer Engineering at MSA University, Egypt.

## Public sections
- Research
- Selected research evidence pages
- Publications
- Teaching and student research
- About and academic background
- Contact and research collaboration
- Public-safe downloadable CV

## Current baseline
**v5.0 Release Candidate**

The site uses standard academic terminology and an evidence-first structure: selected research links from project summaries to concise evidence pages and publication records.

The public CV is generated during the GitHub Pages build from `scripts/generate_public_cv.py` so that its public-safe content remains reproducible.

## Privacy rule
The public portfolio excludes confidential institutional information, student records, private commercial or financial information, unpublished project details, and professional claims that have not been sufficiently reconciled for public use.

Deployed with GitHub Pages from `main`.
